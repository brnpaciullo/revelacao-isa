# Studio Nami — site

Site institucional do Studio Nami (terapias corporais), com agendamento pelo WhatsApp.

- `index.html` — estrutura e textos das seções
- `src/main.js` — lista de terapias (`TERAPIAS`) e número do WhatsApp (`WHATSAPP`)
- `src/style.css` — identidade visual (paleta oceano / água / areia / luz)
- `public/img/` — logo e fotos recortadas do moodboard

```bash
npm install
npm run dev     # desenvolvimento
npm run build   # gera dist/ (é o que a Vercel publica)
```

O projeto anterior (chá revelação) está guardado em `.bkp/`.
